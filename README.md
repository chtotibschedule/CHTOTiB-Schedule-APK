# 📚 Расписание ЧТОТиБ

Удобное приложение для Android, в котором всегда под рукой расписание занятий вашей группы. Никаких долгих поисков по сайту: выбрали группу один раз и пользуетесь.

> Неофициальное приложение. Расписание берётся с общедоступных страниц сайта [chtotib.ru](https://www.chtotib.ru/schedule_gl/cg.htm).

## ✨ Что умеет приложение

- **Выбор группы один раз.** При первом запуске выберите свою группу (есть поиск), дальше приложение её запомнит. Сменить группу можно в любой момент кнопкой «Сменить».
- **Вкладка «Один день»** показывает ближайший день, когда у вашей группы есть пары. Выходные и свободные дни пропускаются.
- **Вкладка «Неделя»** показывает расписание по дням на две недели: «Ближайшая» и «Следующая». Если на этой неделе пар уже не будет, «Ближайшая» сама покажет следующую неделю.
- **Понятная карточка пары:**
  ```
  №2 | 09:55 — 11:25
  Название дисциплины
  Преподаватель | Кабинет
  ```
- **Деление на подгруппы.** Если пара идёт не у всей группы, справа от кабинета появляется подпись **«Подгруппа 1»** или **«Подгруппа 2»**. Для пар у всей группы подписи нет.
- **Время пар всегда актуальное:** учитывается обычное и сокращённое расписание звонков (например, в предпраздничные дни).
- **Уведомления об изменениях.** Когда расписание на сайте обновилось, приложение присылает уведомление. Иногда приходят и важные объявления.
- **Тёмное яркое оформление**, удобное для чтения.
- Работает на **Android 8.0 и новее**.

## 📲 Установка

1. Скачайте файл `.apk` последней версии на вкладке [**Releases**](../../releases) (раздел справа на странице репозитория).
2. Откройте скачанный файл. Если телефон попросит, разрешите установку из этого источника (браузер или «Файлы»).
3. Если Google Play Защита покажет предупреждение «Приложение не проверено», нажмите **«Подробнее» → «Всё равно установить»**. Это стандартное предупреждение для приложений, которые устанавливаются не из магазина.
4. Запустите приложение и разрешите уведомления, чтобы не пропускать изменения в расписании.
5. Выберите свою группу, и всё готово.

### 🔄 Обновление

Скачайте новую версию с вкладки Releases и установите поверх старой. Выбранная группа сохранится.

## ❓ Частые вопросы

**Уведомления приходят с опозданием или не приходят.**
На некоторых телефонах (Xiaomi, Huawei, Honor, Realme и др.) система «усыпляет» приложения. Откройте настройки приложения и отключите ограничения: *Батарея → Без ограничений* (или «Автозапуск» и «Работа в фоне»). Также проверьте, что уведомления для приложения включены.

**Расписание не загружается.**
Проверьте подключение к интернету и нажмите кнопку **↻** в правом верхнем углу. Приложение получает данные с сайта колледжа, поэтому, если сайт временно недоступен, расписание тоже не откроется.

**Показывается не то расписание или время пары выглядит неверно.**
Нажмите **↻**, чтобы обновить данные. Если ошибка осталась, создайте обращение в разделе [Issues](../../issues) и приложите скриншот.

**Как сменить группу?**
Нажмите «Сменить» в верхней части экрана и выберите другую группу.

## 📄 Отказ от ответственности

Приложение не связано с администрацией колледжа. Информация загружается с сайта колледжа, и за её точность отвечает его владелец. Если есть сомнения, сверяйтесь с расписанием на сайте или в учебной части.
